# Phase 1.5B — Analysis Session Card

This checkpoint adds a persistent top-right Analysis Session card.

The card summarizes:

- detected dataset family;
- uploaded filename;
- row and column counts;
- detected years, subjects, and grades when available;
- current AI-generated chart type;
- key active spec filters.

The card begins in an empty state and updates automatically after upload and after a chart specification is generated. The existing New Analysis workflow remains unchanged.
