# Phase 3B — Evidence Engine

VizCreate now follows a consistent guided-analysis sequence:

1. Visualization — show the evidence.
2. Insights — understand the visualization.
3. VizCreate Insights — detect patterns in the current filtered data.
4. Dive Deeper — recommend the next investigation using context and evidence.

The deterministic Evidence Engine produces a one-sentence overview, up to three
observations, educational interpretations, confidence badges, confidence
rationales, and evidence-aware recommendation hints.

Investigation history now stores visualization insights and evidence findings,
providing the foundation for Phase 4 summaries of either the current view or the
entire investigation.
