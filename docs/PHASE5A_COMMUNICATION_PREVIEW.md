# Phase 5A — Communication Preview

## Purpose

Phase 5A does not write a finished report for the user. It organizes the basic
materials needed to create a presentation, memo, board update, discussion guide,
or locally authored report.

## Scope choices

- Current Visualization
- Entire Investigation

## Contents

Each analysis includes:

1. Question Asked
2. Applied Scope
3. Visualization
4. Insights Given
5. Common Language Translation

The entire-investigation preview preserves the order in which questions were
answered. It does not collapse separate analyses into a single generic report.

## Common Language Translation

The translation converts existing VizCreate evidence into accessible
professional language. It does not:

- invent explanations
- prescribe action
- imply causation
- add findings that were not produced by the analysis

## Visualization memory

Phase 5A stores PNG bytes with each completed analysis. This allows the Entire
Investigation preview to display the visualization associated with each earlier
question.

Analyses completed before this version may not contain a stored image. The
preview identifies that limitation rather than substituting the current chart.

## Future Phase 5C compatibility

The Communication Preview is structured so the same question, scope, PNG,
insights, and translation records can later be exported without changing the
investigation-memory model.
